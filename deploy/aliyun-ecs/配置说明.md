# 课堂答题系统 - 阿里云 ECS 部署配置说明

> 本项目为纯 Node.js + Express 应用（无任何云厂商强依赖），可部署在阿里云 ECS、任意云服务器或本地。
> 数据持久化在 `DATA_DIR`（默认 `/data/store.json`）——**ECS 磁盘本身持久，无需额外挂载云盘**。

---

## 一、推荐架构

```
学生/教师浏览器
     │  HTTPS(443)
     ▼
Nginx（反向代理 + SSL 证书）──── 80 ──── Docker 容器（node:18，监听 80）
     │
     ▼
ECS 磁盘 /data/store.json（数据持久化，重启不丢）
```

- 不需要数据库、不需要对象存储、不需要消息队列——全部数据就是一个 JSON 文件。
- 实例规格：**1 核 1G 足够**（教学场景并发低）。系统盘 40G 起步即可，数据量很小（真题库约几 MB 级）。

---

## 二、部署步骤（ECS + Docker）

> **当前实际系统：Alibaba Cloud Linux（阿里云 Linux 3）**——RHEL/CentOS 兼容系，直接用下面的 `yum` 命令装 Docker 即可。

### 1. 购买 ECS
- 阿里云控制台 → 云服务器 ECS → 创建实例。镜像选 **Alibaba Cloud Linux 3**（或 Ubuntu 22.04 / CentOS 均可）。
- 公网 IP 默认分配。安全组需放行：**80（HTTP）、443（HTTPS，可选）**。SSH 22 默认已放行。
- 如果已有服务器，跳过此步。

### 2. 安装 Docker + git（一次性，Alibaba Cloud Linux）
```bash
yum install -y git yum-utils
yum-config-manager --add-repo https://download.docker.com/linux/centos/docker-ce.repo
yum install -y docker-ce docker-ce-cli containerd.io
systemctl enable --now docker
docker --version        # 有版本号即成功
```
> 若 `yum install docker-ce` 因网络/源失败，可换阿里云镜像源：
> ```bash
> yum-config-manager --add-repo https://mirrors.aliyun.com/docker-ce/linux/centos/docker-ce.repo
> yum install -y docker-ce docker-ce-cli containerd.io
> ```
> Ubuntu 系统则用：`curl -fsSL https://get.docker.com | sh`

### 3. 上传代码
方式一（推荐，代码在 GitHub）：
```bash
git clone https://github.com/huzhiji/classroom-poll-tcb.git /opt/classroom
cd /opt/classroom
```
方式二：从本地打包上传（`scp -r` 或宝塔面板上传后解压）。

### 4. 一键部署
```bash
cd /opt/classroom
bash deploy/aliyun-ecs/deploy.sh
```
脚本会：构建镜像 → 删除旧容器 → 启动新容器（自动重启、数据挂载 `/data`）。

部署完成即可访问：
- 教师端：`http://<公网IP>/teacher.html`
- 学生端：`http://<公网IP>/student.html`

### 5. 常用运维命令
```bash
docker logs -f classroom        # 看日志
docker restart classroom        # 重启
docker stop classroom           # 停止
cd /opt/classroom && bash deploy/aliyun-ecs/deploy.sh   # 更新代码后重新部署（数据不丢）
```

## 三、环境变量说明

| 变量 | 默认 | 说明 |
|---|---|---|
| `PORT` | `80` | 应用监听端口。容器内固定 80，外部映射靠 `-p` |
| `DATA_DIR` | `/data` | 数据文件目录（`store.json` 持久化于此）。**建议保持 `/data`，勿改** |
| `APP_URL` | 空 | 你的访问域名，如 `https://exam.example.com`。邮件提醒里的按钮链接用到。**未设置则不生成链接** |
| `SMTP_HOST` | 空 | 发信 SMTP 服务器（如 `smtp.qq.com`）。不配则邮件提醒不可用，其余功能正常 |
| `SMTP_PORT` | `465` | SMTP 端口，465=SSL |
| `SMTP_USER` | 空 | 发信邮箱 |
| `SMTP_PASS` | 空 | 邮箱授权码（非登录密码） |
| `SMTP_FROM` | 同 SMTP_USER | 发件人显示地址 |
| `AUTO_REMINDER` | `0` | 设为 `1` 启用每日自动复习提醒邮件 |
| `REMINDER_HOUR` | `9` | 每日自动提醒的小时（0-23） |

配置方法：编辑 `deploy/aliyun-ecs/deploy.sh` 顶部的配置区，然后重跑脚本即可（数据不会丢）。

## 四、绑定域名 + HTTPS（推荐）

### 1. 域名解析
阿里云 DNS → 添加解析：A 记录 → `@` 和 `www` → ECS 公网 IP。

### 2. 申请免费证书
阿里云控制台 → 数字证书管理服务（原 SSL 证书）→ 免费证书 → 创建/申请（单域名证书即可）→ 下载 **Nginx** 格式证书。

### 3. 配置 Nginx 反代
安装 Nginx 后，把证书 `.pem` 和 `.key` 上传到 `/etc/nginx/certs/`，参考本项目 `deploy/aliyun-ecs/nginx.conf` 配置：
```bash
cp deploy/aliyun-ecs/nginx.conf /etc/nginx/conf.d/classroom.conf
# 修改 nginx.conf 里的域名、证书路径后：
sudo nginx -t && sudo systemctl reload nginx
```

### 4. 设置 APP_URL / SMTP（推荐用 .env.local，自动更新不丢）
在服务器上创建 `deploy/aliyun-ecs/.env.local`（每行 `变量=值`）：
```bash
cat > /opt/classroom/deploy/aliyun-ecs/.env.local <<'EOF'
APP_URL=https://你的域名
SMTP_HOST=smtp.qq.com
SMTP_PORT=465
SMTP_USER=你的发信邮箱
SMTP_PASS=邮箱授权码
AUTO_REMINDER=1
EOF
```
该文件已被 .gitignore 排除，**代码更新时不会被覆盖**；deploy.sh 会自动读取它。

## 五、数据备份（重要）

- 数据在 ECS 的 `/data/store.json`。定期备份到本地：
  - 网页端：教师端 → 「数据备份」Tab → 「下载完整数据到本地」（导出 JSON 存档）。
  - 命令行：`docker exec classroom sh -c 'cat /data/store.json' > backup-$(date +%F).json`
  - 或配置阿里云快照（云盘自动快照），双保险。
- 换机器/迁移：把整个 `/data` 目录拷贝到新机器，重新部署后数据即恢复。

## 六、自动同步（本地改完 → 服务器自动上线，推荐）

> 目标是：**在这台电脑上改代码 → push 到 GitHub → 服务器自己拉取并重新部署**，全程不用再登服务器。

```
本地电脑（WorkBuddy 改代码）──git push──▶ GitHub(main) ──每2分钟检查──▶ 服务器自动 git pull + 重建容器
```

### 一次性配置（服务器上，root 执行）
在服务器已完成首次部署（`/opt/classroom` 存在）后执行：
```bash
chmod +x /opt/classroom/deploy/aliyun-ecs/auto-update.sh
echo '*/2 * * * * root /opt/classroom/deploy/aliyun-ecs/auto-update.sh' > /etc/cron.d/classroom-autodeploy
systemctl enable --now crond   # 若未安装：yum install -y cronie
```
- `*/2` = 每 2 分钟检查一次（想更及时改成 `*/1`）。
- 之后每次 push 到 main，**1~2 分钟内服务器自动更新上线**。
- 日志：`/opt/classroom/.autodeploy.log`；查看是否正常：`tail -5 /opt/classroom/.autodeploy.log`。
- 想关掉自动同步：`rm /etc/cron.d/classroom-autodeploy`。

### 你的 SMTP/APP_URL 配置会被覆盖吗？
不会。请把个性化配置写在 `deploy/aliyun-ecs/.env.local`（见「四、绑定域名」第 4 点），该文件被 .gitignore 排除，自动拉取不会动它。

### 进阶：GitHub Actions 秒级部署（可选）
若想让 push 后**立刻**部署（不等 2 分钟），可用 GitHub Actions：在仓库 Settings → Secrets 里配置服务器 IP/账号/SSH 私钥，再提交一个 workflow 文件，push 即自动 SSH 到服务器执行更新。需要的话我可以帮你配好。

## 七、常见问题

**Q：访问不了？**
先 `curl http://localhost/` 在服务器内测；通了则是安全组没放行 80/443，去安全组配置加规则。

**Q：换域名/端口后邮件链接不对？**
设置 `APP_URL` 后重新跑 deploy.sh。

**Q：想换回直跑 Node（不用 Docker）？**
```bash
cd /opt/classroom
npm install --production
DATA_DIR=/data PORT=80 node index.js
# 或用 pm2：npm i -g pm2 && DATA_DIR=/data PORT=80 pm2 start index.js
```
数据仍在 `/data`，与 Docker 版互通。
