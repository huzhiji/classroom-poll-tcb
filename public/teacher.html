按时间窗统计全班与每个人的掌握情况、薄弱点及提升建议。可手动生成周报（近7天）或月报（本月累计）；若配置了大模型，报告将用 AI 生成分析文本，否则使用内置规则分析。

🤖 AI 分析配置 可选

系统已默认指向火山方舟（Volcengine Ark）云端大模型：国内稳定、无需本机装显卡/模型，填入 API Key 即用。也可切回本地 Ollama（免 key）。调用失败自动回退内置规则分析，不影响报告发布。

💡 说明：系统自动生成报告时，AI 分析文本由上方配置的接口生成。若未配置或调用失败，可在 WorkBuddy 对话中把报告数据交给我（AI 助手）润色，再把文字贴回报告备注。

✅ 方案 A（推荐·云端火山方舟，稳定免运维）：在火山方舟控制台「模型推理」开通任一模型并创建 API Key 后，本页默认 endpoint=https://ark.cn-beijing.volces.com/api/v3、model=deepseek-v4-flash-260425，粘贴 Key 点「保存配置」即可。
① 开通模型：控制台 → 模型推理 → 开通模型（如 deepseek-v4-flash-260425 / doubao-seed-2-1-pro-260628，未开通会报 ModelNotOpen）
② 创建 API Key：控制台 → API Key 管理 → 复制 ark-... 密钥
③ 本页粘贴 Key（Key 必填，云端不校验也可留空但建议填），点「保存配置」。
注：API Base URL 为 https://ark.cn-beijing.volces.com/api/v3（OpenAI 兼容）。

⚠️ 方案 B（本地模型 Ollama，零成本但需本机有显卡）：若不想用云端，把 endpoint 改为 http://127.0.0.1:11434/v1、model 改为 qwen2.5:7b，Key 留空即可（Ollama 须与系统同机运行：ollama serve + ollama pull qwen2.5:7b）。
注：原七牛云 AI Token API 实测账号被风控封禁（403 account_chat_banned），已弃用。
